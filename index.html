Group full-stack project

Let Me Cook — Recipe App

Project overview

Let Me Cook is a full-stack recipe and meal-planning web application built for university students who are managing meals with limited time, budget, cooking experience, and dietary constraints. The application recommends recipes based on available ingredients, dietary restrictions, budget goals, health goals, cuisine preferences, meal type, cooking time, ingredient availability, and rating.

The final system supported secure user accounts, profile-based preferences, recipe search and filtering, ingredient-based recipe matching, recipe scaling, recipe reviews, favourites, tried recipes, personal notes, budget-aware recommendations, nutritional information, cost estimates, ingredient substitutes, help icons, and a responsive interface.
