Overview

Let it Cook is a full-stack web application designed to help university students manage meals after moving out independently. Unlike generic recipe sites, it adapts to each user's dietary restrictions, available ingredients, budget, and nutritional goals — combining ingredient-aware search, real-time budget tracking, substitution suggestions, and a community review system into one student-friendly tool.

Problem & Motivation

University students with limited time, cooking experience, and tight budgets struggle to plan and prepare their own meals. Existing solutions don't account for multiple constraints simultaneously. This platform was built to address that gap — enabling students to find recipes they can actually make, with what they already have, within what they can afford.

NLP · LLM Research · Independent Project
LLM Evaluation Framework
Automated Q&A assessment pipeline — 99% pass rate across 6 topic categories
Overview

A from-scratch Python evaluation pipeline for measuring large language model performance on Q&A tasks. The framework integrates the Groq API with Llama 3.3 70B, runs responses through two independent scoring methods — LLM-as-judge and human review — and compares their agreement to surface bias in automated evaluation. The project resulted in a 99% pass rate across a 20-question dataset spanning 6 topic categories, with full scoring analysis and reliability metrics.

Motivation

As LLMs are increasingly deployed in production Q&A systems, reliable evaluation is critical — and purely human review doesn't scale. This project set out to build a reproducible, automated evaluation harness and rigorously test whether LLM-as-judge scoring can substitute for human judgment, identifying where the two methods agree, diverge, and introduce bias.

What I Built
  • 20-question evaluation dataset — hand-curated across 6 distinct topic categories to stress-test chatbot consistency and surface category-level performance differences.
  • Groq API integration — connected to Llama 3.3 70B with structured prompt templates ensuring reproducible, parseable responses across all evaluation runs.
  • LLM-as-judge scoring — implemented a secondary LLM judge that evaluates each chatbot response against a ground-truth rubric, returning structured pass/fail scores with reasoning.
  • Human review scoring — designed a parallel human evaluation protocol to independently score the same responses, enabling direct method comparison.
  • Scorer agreement analysis — quantified alignment between the two scoring methods across all 6 topic categories, measuring where automated evaluation is reliable and where it diverges from human judgment.
  • Bias analysis — identified systematic tendencies in LLM-as-judge scoring (e.g., leniency or harshness by topic type) and documented their implications for automated evaluation at scale.
  • Performance report — produced a structured findings document covering pass rates, category breakdowns, scorer agreement rates, and recommendations for LLM eval design.
Results
  • Achieved a 99% pass rate across the full 20-question dataset under both scoring methods.
  • Both LLM-as-judge and human review scores showed high agreement overall, validating the automated pipeline for this task class.
  • Identified topic-specific divergence between scorers in categories requiring nuanced or subjective judgment, highlighting areas where human review remains essential.
  • Documented bias patterns in LLM-as-judge scoring that inform best practices for automated evaluation harness design.
